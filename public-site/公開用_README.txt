NPCマップ v3.7 一般公開用

このフォルダにある index.html、images フォルダ、category-styles.json のみを GitHub リポジトリ直下へ置きます。
「管理者用_PCで起動」フォルダや承認待ちCSVは絶対にアップロードしないでください。

公開データ：GoogleスプレッドシートのCSV公開URLから読み込みます。変更は数分遅れることがあります。
カテゴリ色・アイコンを変更したい場合は管理者用からJSONを書き出し、このフォルダのcategory-styles.jsonを置き換えてから公開してください。

GitHub Pagesが以前エラーになっていた場合、リポジトリ Settings > Pages でデプロイ状況を確認。問題が続く場合は別の静的ホスティングを選べます。
ゲーム画像の一般公開前に利用規約・権利をご確認ください。
